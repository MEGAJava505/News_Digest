# 📰 Kun.uz Automated News Digest & Sentiment Analysis

**Kun.uz News Digest** — это автоматизированная система для сбора, анализа и рассылки новостей. Программа собирает последние новости с популярного узбекского портала Kun.uz, проводит анализ тональности (Sentiment Analysis) и отправляет персонализированные HTML-письма пользователям на основе их интересов. Запуск рассылки удобно управляется через Telegram-бота.

---

## 🚀 Основной функционал

1. **Автоматический сбор данных (RSS Parsing)**
   - Программа автоматически подключается к официальной RSS-ленте `kun.uz/news/rss` и извлекает самые свежие статьи.
   - Извлекаются заголовки, описания, категории, даты публикации и ссылки на полные статьи.
   - Парсер `BeautifulSoup4` переходит по ссылкам и извлекает реальные обложки новостей (тег `og:image`).

2. **Мультиязычный анализ тональности (Sentiment Analysis)**
   - Поскольку инструменты анализа тональности лучше работают на английском языке, текст новостей (заголовок + описание) на узбекском "на лету" переводится на английский язык с помощью `deep-translator`.
   - Переведенный текст анализируется с использованием мощной библиотеки **VADER Sentiment Analysis**.
   - Каждая новость получает оценку от `0` до `10` и классифицируется как:
     - 🟢 **Ijobiy (Позитивная)**: Зеленая шкала
     - 🟡 **Neytral (Нейтральная)**: Желтая шкала
     - 🔴 **Salbiy (Негативная)**: Красная шкала

3. **Управление пользователями (Excel Integration)**
   - База пользователей хранится в удобном файле `users.xlsx` (управляется через скрипт `create_test_data.py`).
   - Поддерживается **категоризация**: пользователь может выбрать любимую тему (например, `iqtisodiyot` — экономика, `sport`, `texnologiya` и т.д.).
   - Поддерживается **математическая фильтрация по тональности**: например, фильтр `<4` отправит только самые негативные или проблемные новости.

4. **Генерация HTML-писем (Jinja2 Templating)**
   - Письма формируются на основе профессионального табличного HTML-шаблона (`template.html`).
   - Использование таблиц (а не `flexbox`) гарантирует идеальное отображение во всех почтовых клиентах (Gmail, Outlook, Yandex, Apple Mail).
   - В письмо встраиваются реальные картинки статей, стилизованные метки категорий и визуальные шкалы (Progress Bars) оценки сентимента.

5. **Telegram Bot интеграция**
   - Больше не нужно запускать скрипт вручную. Система интегрирована с Telegram через `python-telegram-bot`.
   - Достаточно написать боту букву **«О»**, и он мгновенно запустит процесс сбора новостей, анализа и массовой рассылки писем всем пользователям из базы.

## 🛠️ Стек технологий

*   **Язык программирования:** Python 3.x
*   **Сбор данных:** `feedparser`, `requests`, `BeautifulSoup4`
*   **Анализ данных и перевод:** `vaderSentiment`, `deep-translator`
*   **Рендеринг:** `Jinja2`
*   **Управление данными:** `openpyxl` (чтение/запись Excel)
*   **Рассылка (SMTP):** встроенный модуль `smtplib` + `email.mime`
*   **Telegram Бот:** `python-telegram-bot`
*   **Конфиденциальность:** `python-dotenv` (все пароли и токены скрыты в файле `.env`)

---

## 📂 Структура проекта

*   `src/` — Исходный код приложения
    *   `main.py` — Главный движок программы: классы для парсинга, анализа и отправки писем.
    *   `bot.py` — Telegram-бот, который ожидает команд и триггерит выполнение функции из `main.py`.
*   `templates/` — HTML шаблоны
    *   `template.html` — Шаблон рассылки (HTML + CSS inline-стили).
    *   `newsletter_template.html` — Дополнительный шаблон рассылки.
*   `data/` — Данные
    *   `users.xlsx` — Excel-файл со столбцами: Имя, Email, Интересы, Фильтр тональности.
    *   `sus.txt`, `plan.txt` — Текстовые данные проекта.
*   `scripts/` — Скрипты
    *   `create_test_data.py` — Скрипт для быстрого создания или обновления базы данных пользователей.
    *   `test_sentiment.py`, `test_sentiment2.py` — Тестовые скрипты.
*   `.env` — Файл (не попадает в Git), хранящий настройки SMTP, почты и токен Telegram-бота.

## 💡 Как это работает: Пример User Flow

1. Пользователь "Azam" добавлен в Excel со следующими настройками: Интерес = `iqtisodiyot`, Фильтр = `<4`.
2. Вы открываете Telegram и отправляете боту сообщение `О`.
3. Скрипт скачивает 15 последних свежих новостей с `kun.uz`.
4. Из них отбираются новости, касающиеся экономики (`iqtisodiyot`).
5. Отобранные новости переводятся, и для них высчитывается Sentiment Score.
6. В итоговый список попадают только те новости по экономике, оценка которых строго меньше 4.
7. Система генерирует красивое письмо на узбекском языке с заголовком, например: *"The Brief - 2 ta yangilik"*.
8. Через Gmail SMTP письмо отправляется Азаму на почту. Бот в Telegram рапортует об успешном окончании работы.
